# 📖 企業級英語拼字測驗與學習追蹤系統 (English Spelling Learning System)

這是一套基於 Java Spring Boot 開發的前後端分離 Web 應用程式，專為企業內部英語學習需求量身打造的動態測驗與成效追蹤平台。系統嚴格落實 MVC 架構，並具備雙身分（學生前台/教師後台）權限管控、防作弊機制與個人化錯題本功能。

## 🛠️ 技術架構 (Tech Stack)

* **Backend:** Java 17, Spring Boot 3.2.4
* **Architecture:** MVC (Model-View-Controller), RESTful API 設計
* **Frontend:** HTML5, Vanilla JavaScript, CSS3, Chart.js
* **Database:** MySQL / Spring Data JPA (關聯式資料庫設計與實體映射)
* **Deployment:** 雲端伺服器 (具備自動休眠喚醒處理機制)

---

## ✨ 核心系統功能 (Core Features)

### 🧑‍🎓 學生端前台模組 (Student Portal)

#### 1. 註冊分流與嚴密防護機制 (Registration & Security)
* **嚴謹的分組綁定**：學生於系統註冊時需自主選擇事前分配的所屬組別（A組至F組），系統寫入資料庫後即永久綁定該權限。後續登入測驗時，僅允許學生透過 Modal 彈窗自由選擇 1 至 10 回的測驗進度，系統將自動載入對應組別的專屬題庫。
* **防堵作弊的路由攔截**：實作前端 `History API` (`window.history.replaceState` 與 `location.replace()`)，徹底抹除測驗頁面的歷史紀錄，防止使用者透過瀏覽器的「上一頁」返回考卷作弊或觸發重複交卷異常。
* **動態題型渲染**：支援多種題型混合解析，包含圖片辨識、情境對話格式化，以及支援多重空格的段落克漏字填空。

#### 2. 智慧錯題本與銷案邏輯 (Smart Error Review)
* **精準錯誤捕捉**：測驗提交後，系統自動將錯誤題型與學生的錯誤答案同步寫入關聯資料庫。
* **兩次容錯與引導機制**：錯題本具備智慧防呆，連續答錯兩次才會顯示正確解答提示，避免學生過度依賴解答。
* **強制肌肉記憶銷案**：學生必須在錯題本中手動拼出完全正確的單字，才能呼叫 API 完成「銷案」並將該題移出錯題本。

#### 3. 學習成效視覺化 (Data Visualization)
* **圖表化數據追蹤**：整合 Chart.js，將後端撈取的歷史戰績陣列轉化為直觀的學習折線圖。
* **多維度資料過濾**：提供「所有回數總覽」與「單一回數分析」的過濾器，無須重新載入頁面即可即時重繪學習曲線。

### 👨‍🏫 教師端後台模組 (Teacher Analytics Portal)

#### 1. 學習成效監控 (Performance Analytics)
* **班級數據統整**：提供教師專屬的總覽儀表板，可即時查看個別學生的測驗完成度與歷史成績走勢。
* **學習弱點追蹤**：協助教師掌握學生在各組別與各回數的表現差異，分析常見錯題分佈，以利精準調整後續教學方針與輔導策略。

## 💡 架構設計亮點

本專案後端採用企業級分層設計，明確劃分 Controller (負責路由與 API 封裝)、Service (處理核心業務邏輯，如成績計算與權限驗證) 與 Repository (專注資料庫存取)。前端為追求極致的載入效能與雲端環境適應性，捨棄沉重的大型框架，採用純原生 JavaScript 搭配 Fetch API 達成高效的非同步資料交換，兼顧了系統的輕量化與高可維護性。
